## 3.1. Python

Python é uma linguagem de programação de alto nível, amplamente utilizada no desenvolvimento de sistemas, automações, aplicações científicas e análise de dados.

## 3.2. Objetivo

O objetivo da implementação é desenvolver um sistema capaz de realizar, de forma automatizada, a verificação das condições operacionais da nave antes da decolagem.

A partir dos dados de telemetria, o programa analisa os parâmetros definidos, identifica possíveis condições de falha e determina o estado final do sistema, indicando `DECOLAR` quando todos os critérios são atendidos ou `ABORTAR` quando pelo menos uma condição de segurança não é satisfeita.

---

## 3.3 Estrutura do Programa

O programa foi estruturado em funções, permitindo organizar cada etapa do processo de análise de forma independente. Essa abordagem contribui para a organização do código, facilita sua manutenção e torna a lógica do sistema mais clara.

O fluxo principal da aplicação é composto pelas seguintes etapas::

```text
Iniciar o sistema
 ↓
Gerar dados simulados dos sensores
 ↓
Apresentar os dados de telemetria
 ↓
Verificar os limites dos parâmetros
 ↓
Registrar possíveis falhas
 ↓
Determinar DECOLAR ou ABORTAR
```

> A divisão do programa em etapas permite representar, de maneira organizada, o fluxo de análise da telemetria durante a verificação de pré-decolagem.

## 3.4. Bibliotecas Utilizadas

Para a implementação da simulação de telemetria, foram utilizadas duas bibliotecas nativas do Python: `random` e `datetime`.

`random`

A biblioteca `random` é utilizada para gerar valores pseudoaleatórios. No projeto, ela permite simular informações que poderiam ser obtidas por meio dos sensores da nave, como temperaturas, pressão e nível de energia.

Entre as funções utilizadas estão:

`random.uniform()`: geração de valores decimais dentro de um intervalo;
`random.randint()`: geração de valores inteiros dentro de um intervalo;
`random.choice()`: seleção aleatória de um elemento entre as opções disponíveis.

`datetime`

A biblioteca `datetime` é utilizada para obter e formatar a data em que os dados de telemetria são gerados.

No projeto, a função `datetime.now()` permite registrar a data atual da execução do programa.

## 3.5 Explicação do Codigo

---
### 3.5.1 Gerar dos Dados de Telemetria

A função `dados_telemetria()` é responsável por gerar os dados simulados que representam as informações recebidas pelos sensores e sistemas da nave.

```python
def dados_telemetria():
    return {
        "DATA": datetime.now().strftime("%d/%m/%Y"),
        "T_INT": round(random.uniform(10, 35), 2),
        "T_EXT": round(random.uniform(-60, 60), 2),
        "STR": random.randint(0, 1),
        "PWR": round(random.uniform(50, 100), 2),
        "PRS": round(random.uniform(100, 350), 2),
        "MOD": random.choice(["OK", "FALHA"])"])
}
```

> Os valores gerados são armazenados em um dicionário Python, no qual cada informação é associada a uma chave específica.

---

### 3.5.2 Exibição da Telemetria

Após a geração dos dados, a função `exibir_telemetria()` é responsável por apresentar as informações recebidas de forma organizada no terminal.

```python
def exibir_telemetria(dados):

    print("==================================================")
    print(" 2.RECEBIMENTO DOS DADOS")
    print("==================================================")
    print(" ")

    print(f"Data:{dados['DATA']}")
    print(f"Temperatura interna: {dados['T_INT']}")
    print(f"Temperatura externa: {dados['T_EXT']}")
    print(f"Integridade estrutural: {dados['STR']}")
    print(f"Nível de energia: {dados['PWR']}")
    print(f"Pressão dos tanques: {dados['PRS']}")
    print(f"Módulos críticos: {dados['MOD']}")
```
A função recebe o dicionário gerado anteriormente como parâmetro e utiliza suas chaves para acessar e apresentar cada informação individualmente.

> Essa etapa permite visualizar os dados que serão posteriormente submetidos ao processo de validação.

---
### 3.5.3 Validação dos Parâmetros

A função `validar_parametros()` implementa os critérios de segurança definidos na [Parte 1 — Telemetria e Parâmetros Operacionais.](https://github.com/stela92s/aurora-siger-pre-decolagem/blob/main/docs/2.algoritimo.md)

Inicialmente, são criadas duas variáveis responsáveis pelo controle do processo de validação:

```python
falhas = []
sistema_ok = True
```

A lista `falhas` é utilizada para armazenar os parâmetros que apresentarem condições classificadas como `NOK`.

A variável `sistema_ok` é inicializada com o valor `True`, indicando que, inicialmente, o sistema é considerado dentro das condições estabelecidas.

Quando uma condição fora dos critérios definidos é identificada, o estado geral do sistema é alterado:

```python
sistema_ok = False
```

> Dessa forma, a identificação de uma única condição fora dos limites estabelecidos é suficiente para alterar o estado geral do sistema para `NOK`.

---

#### 3.5.3.1 Registro das Falhas

Quando um determinado parâmetro não atende aos critérios estabelecidos, sua identificação é adicionada à lista `falhas`.

Por exemplo:

```python
falhas.append("Pressão dos tanques")
```

A utilização de uma lista permite registrar múltiplas falhas durante uma mesma execução do programa.

Dessa forma, o sistema não apenas identifica a existência de uma condição inadequada, mas também registra quais parâmetros apresentaram valores ou estados fora dos critérios definidos.

Ao final do processo de validação, a função retorna duas informações:

```text 
return sistema_ok, falhas
```

O primeiro valor representa o estado geral do sistema, enquanto o segundo contém a relação dos parâmetros que apresentaram falhas.

---

### 3.5.4 Decisão

A função `decisao_final()` ecebe como entrada os resultados obtidos durante a etapa de validação: `def decisao_final(sistema_ok, falhas)`:

A decisão é realizada por meio de uma estrutura condicional que verifica o estado geral do sistema.

```python
if sistema_ok == True:
    print("STATUS: DECOLAR")
else:
    print("STATUS: ABORTAR")

```

> Quando ocorre um `ABORTAR`, o programa também apresenta a quantidade e a identificação das falhas encontradas.

## 3.6 conclusão

A implementação em Python permitiu transformar os critérios de telemetria e a lógica definidos no algoritmo, pseudocódigo e fluxograma em um sistema funcional de simulação para a etapa de pré-decolagem da Aurora Siger.

O programa realiza a geração dos dados simulados de telemetria, apresenta os valores recebidos, verifica individualmente cada parâmetro e registra as condições que não atendem aos critérios operacionais estabelecidos.

Após a conclusão da validação, o sistema consolida os resultados e apresenta uma decisão final:

`DECOLAR`

quando todos os parâmetros estão dentro das condições estabelecidas, ou:

`ABORTAR`

quando pelo menos um dos parâmetros apresenta uma condição classificada como `NOK`.

Dessa forma, a implementação demonstra a integração entre telemetria, definição de parâmetros operacionais, algoritmo, pseudocódigo, fluxograma e programação em Python.
