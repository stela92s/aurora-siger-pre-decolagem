# 🚀 AURORA SIGER

---

## 1. Telemetria e Parâmetros Operacionais

---

## 1.1. Telemetria

A telemetria é o sistema responsável pela coleta, transmissão e monitoramento
dos dados operacionais da nave **Aurora Siger** durante a preparação para
o lançamento.

Os dados coletados pelos sensores permitem acompanhar as condições dos
principais sistemas da nave e verificar se os parâmetros operacionais estão
dentro dos limites estabelecidos.

---

## 1.2. Objetivo

O objetivo do sistema de telemetria é monitorar e validar as condições operacionais da Aurora Siger antes do lançamento.

Para isso, os valores coletados pelos sensores são comparados com critérios previamente definidos. A partir dessa análise, cada parâmetro é classificado como:

* `OK` — condição dentro dos limites estabelecidos;
* `NOK` — condição fora dos limites estabelecidos.

A autorização do lançamento depende do atendimento aos critérios definidos para todos os parâmetros críticos.

---

## 1.3. Parâmetros Monitorados

O sistema de telemetria monitora os seguintes parâmetros:

| ID    | Parâmetro                   | Unidade | Tipo       |
| ----- | --------------------------- | ------- | ---------- |
| T_INT | Temperatura interna         | °C      | Numérico   |
| T_EXT | Temperatura externa         | °C      | Numérico   |
| STR   | Integridade estrutural      | 0/1     | Binário    |
| PWR   | Nível de energia            | %       | Numérico   |
| PRS   | Pressão dos tanques         | PSI     | Numérico   |
| MOD   | Status dos módulos críticos | Estado  | Categórico |

---

## 1.4. Descrição dos Parâmetros

---

### 1.4.1. Temperatura Interna

Representa a temperatura no interior da nave.

```text
Unidade: °C

Limite mínimo: 15 °C
Limite máximo: 30 °C
```
Critério:

```text
15 °C ≤ T_INT ≤ 30 °C → OK
T_INT < 15 °C → NOK
T_INT > 30 °C → NOK
```

---

### 1.4.2. Temperatura Externa

Representa a temperatura do ambiente externo durante a preparação
para o lançamento.

```text
Unidade: °C

Limite mínimo: -50 °C
Limite máximo: 50 °C
```
Critério:

```text
-50 °C ≤ T_EXT ≤ 50 °C → OK
T_EXT < -50 °C → NOK
T_EXT >  50 °C → NOK
```

---

### 1.4.3. Integridade Estrutural

Representa a condição estrutural da nave.

O parâmetro utiliza uma representação binária.

```text
1 → Estrutura íntegra
0 → Estrutura não íntegra
```
Critério:
```text
STR = 1 → OK
STR = 0 → NOK
```

> A integridade estrutural é um parâmetro crítico.
Um resultado `NOK` impede a autorização do lançamento.

---

### 1.4.4. Nível de Energia

Representa a quantidade de energia disponível nos sistemas da nave.

```text
Unidade: %

Limite mínimo: 80%
Limite máximo: 100%
```
Critério:
```text
80% ≤ PWR ≤ 100% → OK
PWR < 80% → NOK
PWR > 100% → NOK
```

---

### 1.4.5. Pressão dos Tanques

Representa a pressão medida no interior dos tanques monitorados.

```text
Unidade: PSI

Limite mínimo: 150 PSI
Limite máximo: 300 PSI
```
Critério
```text
150 PSI ≤ PRS ≤ 300 PSI → OK
PRS < 150 PSI → NOK
PRS > 300 PSI → NOK
```
---

### 1.4.6. Status dos Módulos Críticos

Representa o estado dos sistemas considerados essenciais para
a operação da nave.
```text
OK  → Funcionamento normal
NOK → Condição inadequada
```

Critério
```text
MOD = "OK" → OK
MOD != "OK" → NOK
```

> Caso qualquer módulo crítico esteja em estado diferente de `OK`,
o lançamento não deverá ser autorizado.

---

## 1.5. Critérios de Validação

Cada parâmetro possui um critério específico para determinar sua condição operacional.

| Parâmetro                    | Condição `OK`          | Condição `NOK`                 |
|-----------------------------|------------------------|---------------------------------|
| Temperatura interna      | `15 ≤ T ≤ 30 °C`       | `T < 15 °C` ou `T > 30 °C`      |
| Temperatura externa      | `-50 ≤ T ≤ 50 °C`      | `T < -50 °C` ou `T > 50 °C`     |
| Integridade estrutural   | `Valor = 1`            | `Valor = 0`                     |
| Nível de energia          | `80% ≤ E ≤ 100%`       | `E < 80%` ou `E > 100%`        |
| Pressão dos tanques       | `150 ≤ P ≤ 300 PSI`    | `P < 150 PSI` ou `P > 300 PSI` |
| Módulos críticos          | `Estado = OK`          | `Estado ≠ OK`                  |

---

## 1.6. Resumo

O sistema de telemetria da Aurora Siger utiliza um conjunto de parâmetros para avaliar as condições operacionais da nave antes do lançamento.

Os dados coletados são comparados com limites previamente definidos e classificados individualmente como `OK` ou `NOK`.

A lógica de validação garante que uma condição fora dos limites estabelecidos seja identificada antes da autorização do lançamento, permitindo uma avaliação objetiva e padronizada dos principais parâmetros monitorados.
