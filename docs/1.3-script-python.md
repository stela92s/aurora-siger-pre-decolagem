# 03 — Implementação em Python

## 3.1 Objetivo

A implementação em Python tem como objetivo simular o sistema de verificação pré-decolagem da nave fictícia Aurora Siger.

O programa recebe dados de telemetria, compara cada informação com os limites de segurança definidos e identifica possíveis problemas operacionais.

Ao final da análise, o sistema apresenta uma das duas decisões:

- `PRONTO PARA DECOLAR`
- `DECOLAGEM ABORTADA`

A implementação foi desenvolvida em um **Python Notebook (.ipynb)** utilizando o Google Colab.

---

## 3.2 Dados de telemetria

Os dados utilizados pelo sistema são armazenados em um dicionário Python chamado `dados_telemetria`.

Cada registro representa uma leitura de telemetria da nave.

```python
dados_telemetria = {

    "2": {

        "pressao_tanques": 91,

    "3": {

```
Cada telemetria possui as seguintes informações:

| Informação               | Descrição                          |
| ------------------------ | ---------------------------------- |
| `data`                   | Data da leitura                    |
| `temperatura_interna`    | Temperatura interna da nave em °C  |
| `temperatura_externa`    | Temperatura externa em °C          |
| `integridade_estrutural` | Indica se a estrutura está íntegra |
| `energia`                | Nível de energia disponível em %   |
| `pressao_tanques`        | Pressão dos tanques em PSI         |
| `modulos_criticos`       | Estado dos módulos críticos        |

## 3.3 Limites de segurança

Os limites utilizados pelo programa são definidos por constantes.

Como a Aurora Siger é uma nave fictícia criada para fins acadêmicos, esses valores representam apenas parâmetros simulados para o projeto.

```python
# temperatura interna
TEMP_INTERNA_MIN = 15
TEMP_INTERNA_MAX = 30

# temperatura externa
TEMP_EXTERNA_MIN = -50
TEMP_EXTERNA_MAX = 50

# integridade estrutural
INTEGRIDADE_OK = 1

# energia
ENERGIA_MIN = 80
ENERGIA_MAX = 100

# pressão dos tanques
PRESSAO_MIN = 150
PRESSAO_MAX = 300

# módulos críticos
MODULOS_OK = "OK"
```
O sistema considera uma condição segura quando todos os valores estão dentro dos limites estabelecidos.

## 3.4 Seleção da telemetria

O usuário pode escolher qual registro deseja analisar.

A função `selecionar_telemetria()` apresenta as opções disponíveis e retorna os dados selecionados.

```python

def selecionar_telemetria():

    print()
    print("SELEÇÃO DA TELEMETRIA")

    print()
    print("1 - 01/09/2026")
    print("2 - 01/08/2026")
    print("3 - 01/07/2026")
    print()

    opcao = input("Digite uma opção: ").strip()

    if opcao not in dados_telemetria:
        print()
        print("Opção inválida.")
        return None

    return dados_telemetria[opcao]

```
A função verifica se a opção digitada existe no dicionário. Caso contrário, apresenta uma mensagem informando que a opção é inválida.

## 3.6 Diagnóstico operacional

A função diagnosticar() é responsável por analisar os dados da telemetria.
Ela verifica cada parâmetro individualmente e registra os problemas encontrados em uma lista chamada problemas.

```python
def diagnosticar(dados):

    problemas = []

    # temperatura interna
    if not (
        TEMP_INTERNA_MIN
        <= dados["temperatura_interna"]
        <= TEMP_INTERNA_MAX
    ):
        print("FALHA: Temperatura interna fora do limite.")
        problemas.append(
            f"Temperatura interna fora do limite: "
            f"{dados['temperatura_interna']} °C."
        )

    # temperatura externa
    if not (
        TEMP_EXTERNA_MIN
        <= dados["temperatura_externa"]
        <= TEMP_EXTERNA_MAX
    ):
        print("FALHA: Temperatura externa fora do limite.")
        problemas.append(
            f"Temperatura externa fora do limite: "
            f"{dados['temperatura_externa']} °C."
        )

    # integridade estrutural
    if dados["integridade_estrutural"] != INTEGRIDADE_OK:
        print("FALHA: Integridade estrutural comprometida.")
        problemas.append(
            "Falha na integridade estrutural."
        )

    # energia
    if not (
        ENERGIA_MIN
        <= dados["energia"]
        <= ENERGIA_MAX
    ):
        print("FALHA: Nível de energia fora do limite.")
        problemas.append(
            f"Nível de energia fora do limite: "
            f"{dados['energia']} %."
        )

    # pressão dos tanques
    if not (
        PRESSAO_MIN
        <= dados["pressao_tanques"]
        <= PRESSAO_MAX
    ):
        print("FALHA: Pressão dos tanques fora do limite.")
        problemas.append(
            f"Pressão dos tanques fora do limite: "
            f"{dados['pressao_tanques']} PSI."
        )

    # módulos críticos
    if dados["modulos_criticos"] != MODULOS_OK:
        print("FALHA: Módulos críticos não estão OK.")
        problemas.append(
            f"Módulos críticos em estado: "
            f"{dados['modulos_criticos']}."

        )

    return problemas
```

## 3.7 Status final
Todos os problemas identificados durante a análise são armazenados na lista problemas.
Após todas as verificações, a função exibir_status_final() determina o resultado da análise.

```python
problemas = []

problemas.append(
    "Falha na integridade estrutural."
)
```
Isso permite que o sistema apresente posteriormente todas as falhas encontradas.

```python
def exibir_status_final(problemas):

    print()
    print("=" * 60)
    print("STATUS FINAL")
    print("=" * 60)

    if len(problemas) == 0:

        print("Nenhum problema detectado.")
        print()
        print(">>> PRONTO PARA DECOLAR <<<")

    else:

        print("Problemas encontrados:")

        for i, problema in enumerate(problemas, start=1):
            print(f"{i}. {problema}")

        print()
        print(f"Total de problemas: {len(problemas)}")
        print()
        print(">>> DECOLAGEM ABORTADA <<<")
```
## 3.8 Execução completa

O sistema principal executa todas as etapas.

```python
print()
print("=" * 60)
print("INICIANDO SISTEMA AURORA SIGER")
print("=" * 60)

while True:

    dados = selecionar_telemetria()

    if dados is None:
        continue

    exibir_telemetria(dados)

    problemas = diagnosticar(dados)

    exibir_status_final(problemas)

    print()
    print("=" * 60)
    print("NOVA CONSULTA")
    print("=" * 60)

    novamente = input(
        "Deseja analisar outra telemetria? (S/N): "
    ).strip().upper()

    if novamente != "S":
        break

print()
print("=" * 60)
print("SISTEMA ENCERRADO")
print("EXECUÇÃO CONCLUÍDA")
print("=" * 60)
```
O `while True` permite que o usuário analise mais de uma telemetria sem precisar reiniciar o programa.
