#  2. Algoritmo, Pseudocódigo e Fluxograma

## 2.1 Algoritmo
Um algoritmo é uma sequência de passos organizados e definidos que permite resolver um problema ou realizar uma determinada tarefa.

Na nave Aurora Siger, o algoritmo será utilizado para analisar os dados recebidos pela telemetria e verificar se a nave apresenta as condições necessárias para realizar o lançamento.

---

## 2.2 objetivo

O objetivo do algoritmo é análisar ds parâmetros de telemetria da Aurora Siger, permitindo verificar de forma organizada se a nave está dentro das condições estabelecidas para o lançamento.
